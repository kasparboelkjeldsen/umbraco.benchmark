Building a Blog with MCP and Umbraco

Published: October 05, 2026

In this guide, we'll walk through the process of building a complete blog site using MCP servers with Umbraco CMS.

The combination of MCP's standardized protocol and Umbraco's flexible content management creates a powerful platform for AI-driven content creation and management.

Here's what we built:

  1. Created document types for blog front page and blog posts
  2. Set up block types for rich text, images, and quotes
  3. Imported images from Unsplash
  4. Created content using MCP tools
  5. Published everything

The entire process was driven through MCP server calls, demonstrating how AI agents can manage content without direct database access or custom API development.

The future of content management is AI-assisted, and MCP is the bridge that makes it possible.
