MCP and Umbraco: A Match Made in the Block Grid

The Umbraco MCP server turns the management API into a conversational workspace — and this very site is the proof, blocks and all.

Updated October 10, 2026

The Umbraco MCP server

An MCP server for Umbraco wraps the management API in tools an agent can call: inspect and edit document types, create and publish content, manage media and templates. The tools are the same ones the backoffice uses — no bolts added, none removed.

That matters for a CMS because so much of the daily work is structural: a content type, a data type, a block. Doing it by hand is click-by-click. With MCP, the same work becomes a conversation.

And the proof is live

Every document type, data type, block, media item and page on this site was created through the Umbraco MCP server. No backoffice clicks, no hand-written migrations — just a conversation with the management API.

That is the demo. The block grid you are reading right now was assembled block by block, one MCP tool call at a time.
