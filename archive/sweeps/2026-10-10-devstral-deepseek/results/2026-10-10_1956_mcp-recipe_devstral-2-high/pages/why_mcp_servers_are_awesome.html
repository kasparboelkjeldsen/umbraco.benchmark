Why MCP Servers Are Awesome

Published: October 10, 2026

MCP (Model Context Protocol) servers are changing the game for AI assistants. They provide a standardized way for AI tools to interact with external systems, databases, and APIs.

In this post, I'll explain why MCP servers are so powerful and how they enable Claude Code to work with Umbraco CMS seamlessly.

With MCP servers, Claude Code can directly interact with Umbraco's management API. This means you can create document types, templates, media items, and content pages without ever leaving your code editor.

The MCP server handles authentication, provides structured tools, and returns data in a format that the AI can easily understand and work with.

MCP servers are the bridge between AI and your applications, making complex integrations simple and accessible.
