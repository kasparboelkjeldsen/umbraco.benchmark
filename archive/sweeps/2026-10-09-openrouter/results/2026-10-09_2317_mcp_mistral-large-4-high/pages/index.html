Why MCP is awesome

Notes from the bench on the Model Context Protocol — the open standard that lets AI agents discover and use the tools they need, this very CMS included.

Every post on this blog is edited in Umbraco's backoffice and rendered with the block grid — no page-builder lock-in, no custom renderers. An MCP server is what makes a workflow like this possible at all: it exposes the CMS's own management API as tools an agent can call.
