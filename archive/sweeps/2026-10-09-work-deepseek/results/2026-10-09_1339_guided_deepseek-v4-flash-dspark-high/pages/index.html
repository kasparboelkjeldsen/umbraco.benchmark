Why MCP is Awesome

This blog site was built entirely through Umbraco's MCP servers — a demonstration of what's possible when AI conversations can design, model, and publish content directly into a CMS.

Built with MCP

Every piece of this site was created through the Umbraco MCP servers — from the document types and data types to the templates, media, and content blocks you see here.

The Model Context Protocol made it possible for an AI assistant to navigate Umbraco's backoffice programmatically, creating a fully functional blog with zero manual clicks.

What was created

  • Content modelling — Element types (heroBlock, richTextBlock), page types (blogFrontPage, blogPost), and a Block Grid data type
  • Media — 10 Unsplash photos imported directly into the media library
  • Pages — A front page with two published blog posts, each with hero and rich text blocks
  • Templates & views — Razor views following AGENTS.md conventions, with ViewComponent-per-block rendering
  • Frontend — Tailwind CSS via Vite build pipeline

All of this without opening a browser. That's the power of MCP.
