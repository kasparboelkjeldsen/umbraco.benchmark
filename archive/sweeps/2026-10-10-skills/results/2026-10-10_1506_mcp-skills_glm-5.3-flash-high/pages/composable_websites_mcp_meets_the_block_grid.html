Composable websites: MCP meets the block grid

Pages are no longer written — they are assembled. Structured blocks, negotiated over MCP, let an assistant compose layouts that editors still own.

A CMS page is not a document — it is a list of composable pieces: a hero, some prose, an image with a caption, a quote. Umbraco's block grid is exactly that contract, and MCP makes it machine-negotiable.

An assistant can inspect the schema, learn which blocks exist and which properties they carry, then assemble a page the same way an editor would click it together — without ever learning the CSS or the markup underneath.

The crucial part: the machine only fills in the content. The schema, the rendering views and the editorial guardrails stay human-owned. That is the promise of MCP in a CMS — automation where it helps, structure where it matters.
