Why MCP is Awesome - Part 2

Published on October 02, 2026

MCP doesn't just standardize tool interfaces - it also provides a framework for resource access. Resources in MCP can represent anything from static data to dynamic APIs.

This means AI agents can not only call functions but also read and write data through a consistent interface.

The real power of MCP comes from its extensibility. Anyone can create an MCP server that exposes their own tools and resources, and any MCP-compliant client can use them.

This creates a vibrant ecosystem where tools can be shared, reused, and combined in novel ways.

The future of AI is interconnected, and MCP is the bridge.
