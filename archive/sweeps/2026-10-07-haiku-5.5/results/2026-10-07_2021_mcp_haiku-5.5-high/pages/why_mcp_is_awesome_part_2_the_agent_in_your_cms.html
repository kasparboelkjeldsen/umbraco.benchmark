Why MCP is awesome, part 2: the agent in your CMS

5 October 2026

This site was modelled, filled and checked by an AI agent talking to Umbraco over MCP. Here is what that looked like and why it matters.

Here the protocol earns its keep. This site was modelled, populated and checked by an agent talking to Umbraco through its MCP server: document types, data types, templates, media and content, all created through tool calls.

The useful part is the feedback loop. The agent reads back what it wrote, and the server exposes each document type's schema, so the agent does not have to guess property aliases or block shapes.

MCP is not a magic wand. It is a clean contract between an agent and a system it can actually operate, and that contract is what made the rest of this site possible.
